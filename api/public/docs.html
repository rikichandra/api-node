01

Mulai dalam tiga langkah

Pekerjaan berjalan di latar belakang. Respons pertama bukan hasil pencarian.

1

Siapkan API key

Tambahkan header X-API-Key pada setiap request ke /v1.

Lihat autentikasi →
2

Kirim daftar customer

Panggil POST /v1/jobs dengan wilayah dan daftar nama usaha. Simpan id dari respons 202.

3

Periksa dan ambil hasil

Cek status job, lalu panggil /results. Gunakan customer.id untuk menggabungkan hasil ke data Anda.

Pin adalah kandidat lokasi. Nama dan provinsi yang cocok belum memastikan identitas atau cabang customer. Cocokkan alamat atau telepon sebelum menggunakan koordinat.
02

Autentikasi & input

API key diberikan oleh administrator layanan. Gunakan HTTPS untuk koneksi dari luar server.

REQUEST HEADERS
X-API-Key: YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: customer-upload-001
FieldTipeKeterangan
regionwajibstringProvinsi/kota tujuan; 2–100 karakter. Contoh: Sumatra Selatan.
customerswajibarray1–1.000 customer; total body maksimal 256 KiB. Mulai dengan batch 100.
customers[].idwajibstringKode customer atau nomor baris; 1–100 karakter, unik dalam satu job.
customers[].namewajibstringNama usaha, 2–200 karakter. Nama perseorangan saja belum cukup.

Upload Excel belum tersedia di endpoint. Ubah baris Excel menjadi array JSON. Untuk retry request yang sama, gunakan Idempotency-Key yang sama (8–128 karakter). Body berbeda dengan key yang sama menghasilkan 409; setelah job dihapus atau kedaluwarsa, key bisa dipakai kembali.

03

Referensi endpoint

Endpoint bisnis memerlukan X-API-Key. Health check dan dokumentasi dapat diakses tanpa key.

Memuat kontrak endpoint…

Daftar dan hasil memakai offset=0 dan limit=100 secara default. Maksimal limit 200. Hasil diurutkan berdasarkan index input.

05
Membaca hasil pencocokan
Respons /results memisahkan identitas input dari kandidat lokasi.

      
Field hasilMakna

        
customer.id / nameIdentitas dan nama dari input Anda. Nama berulang tetap menjadi baris terpisah.

        
match.status / reasonKesimpulan pencocokan dan alasan pemeriksaan.

        
match.bestKandidat yang dipilih untuk ditinjau. Bernilai null jika tidak ada kandidat sesuai.

        
match.candidatesMaksimal tiga alternatif yang detailnya berhasil dibaca.

        
best.lat / lng / mapsUrlKoordinat dan tautan kandidat. Data yang tidak tersedia tetap null/kosong.

        
errorCodeKegagalan pada baris tersebut, misalnya UPSTREAM_TIMEOUT.

      

      
Perhatikan total: job.total adalah jumlah input, job.processed adalah jumlah baris selesai dievaluasi, dan results.total adalah jumlah hasil yang sudah tersimpan. Angka ini bukan jumlah customer yang terkonfirmasi cocok.

    


    

      
06
Status pekerjaan & error
Hasil yang sudah tersimpan tetap tersedia saat job parsial, dibatalkan, atau diblokir.

      
StatusArti & langkah berikutnya

        
queued / runningMenunggu atau berjalan. Periksa status secara berkala; tidak perlu mengirim ulang job.

        
succeededSeluruh baris sudah dievaluasi, termasuk baris tanpa kandidat.

        
partialSelesai dengan sebagian pencarian gagal. Periksa errorCode per baris.

        
blockedGoogle meminta verifikasi/persetujuan. Antrean dijeda sementara; CAPTCHA tidak dilewati.

        
failed / cancelledGagal karena browser/deadline, atau dibatalkan pengguna. Ambil hasil parsial jika tersedia.

      

      
400 / 413
Perbaiki format, field, ID duplikat, atau ukuran body.
401 / 404
Periksa API key dan job ID. Job client lain juga menghasilkan 404.
409 / 429
Konflik idempotensi/job aktif, atau batas request/antrean/penyimpanan.
500 / 503
Gangguan internal atau layanan belum siap. Periksa health dan coba setelah pulih.

      
Default layanan: retensi 7 hari, timeout job 30 menit, cooldown 5 menit, dan batas 120 request/menit per alamat koneksi. Nilai dapat diubah oleh administrator.
